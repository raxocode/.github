# RaxoCode Organization Setup (`.github`)

This repository serves as the organization-wide configuration and profile repository for [RaxoCode](https://github.com/raxocode).

## Profile Entry Point

GitHub automatically displays the profile defined in [`profile/README.md`](profile/README.md) on the main [RaxoCode organization overview page](https://github.com/raxocode).

- **Profile README**: [`profile/README.md`](profile/README.md)
- **Profile Assets**: [`profile/assets/`](profile/assets/)
  - `raxocode-banner.gif`: Optimized animated banner (under 2 MB, seamless 8.67s loop)
  - `raxocode-banner-hd.gif`: High-definition master banner asset
  - `raxocode-banner.png`: Static PNG fallback
  - `raxocode-logo.png`: Brand identity avatar
  - `optimize_banner.py`: Asset inspection, loop verification, and optimization script
